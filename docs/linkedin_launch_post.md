# LinkedIn Project Announcement

🚀 **Excited to share my latest engineering project: An AI-Powered Live Technical Interview Engine Backend!**

Hiring technical talent is time-intensive and challenging to scale. To solve this, I designed and built an event-driven, production-grade backend platform that automates technical candidate interviews end-to-end.

💡 **Key Engineering Highlights:**
- **FastAPI & Async Architecture**: Built on Python 3.12, FastAPI, and SQLAlchemy 2.0 Async to handle high-concurrency non-blocking I/O.
- **Real-Time WebSockets Engine**: Stateful interview rooms backed by a Redis 7 Pub/Sub message bus enabling horizontal multi-node node scaling.
- **AI-Powered Evaluation**: Integrated Google Gemini 1.5 Pro to generate role-tailored questions dynamically and grade answer responses against rubric criteria asynchronously.
- **Deterministic Analytics Engine**: Computes category skill breakdowns and outputs structured hiring recommendations (`STRONG_HIRE`, `HIRE`, `NO_HIRE`).
- **Production Hardening**: Argon2id password security, JWT token rotation, Redis rate limiting, brute force protection, Prometheus observability (`/metrics`), and full CI/CD deployment pipelines.

🛠️ **Tech Stack**: Python 3.12 | FastAPI | PostgreSQL 16 | Redis 7 | Gemini API | Docker | Alembic | Nginx | OpenTelemetry
